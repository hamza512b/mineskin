# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in MineSkin PRO, please report it
responsibly. **Do not open a public issue or post details on Discord.**

Use GitHub's private vulnerability reporting flow:

1. Open the repository's [Security Advisories](https://github.com/hamza512b/mineskin/security/advisories/new) page.
2. Select **Report a vulnerability**.
3. Include the details listed below.

If private vulnerability reporting is unavailable, contact the maintainer
privately using the contact information on the
[maintainer's GitHub profile](https://github.com/hamza512b).

## Scope

The following are in scope:

- The MineSkin PRO web application
- The iOS and Android applications
- Skin import, export, storage, and sharing
- The service worker and offline cache
- Integrations and application configuration maintained in this repository

Third-party services and dependencies should normally be reported to their
respective maintainers unless the vulnerability is caused by MineSkin PRO's use of
them.

## What to include

- A description of the vulnerability and its potential impact
- Clear reproduction steps or a proof of concept
- Affected platforms, versions, routes, or components
- Any suggested mitigation, if available

## Disclosure

Please allow time to investigate and release a fix before sharing details
publicly. When appropriate, the project will credit the reporter unless they
request anonymity and publish a GitHub Security Advisory after a fix is
available.

Thank you for helping protect MineSkin PRO and its users.
