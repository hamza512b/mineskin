# Support

## Get help

- Read the [Usage Guide](USAGE_GUIDE.md) for product help.
- Join the [MineSkin PRO Discord server](https://discord.gg/2egvhmqdza) for questions
  and community support.
- Open a [GitHub issue](https://github.com/hamza512b/mineskin/issues/new/choose)
  for a confirmed bug or an actionable feature request.

## Before opening an issue

- Search [existing issues](https://github.com/hamza512b/mineskin/issues) to
  avoid duplicates.
- Check the [README](README.md) and [Contributing Guide](CONTRIBUTING.md).
- Include reproduction steps, expected behavior, platform and version details,
  and screenshots or recordings when helpful.

Please remember that GitHub issues are public. Do not include private data,
credentials, or skin files you do not have permission to share.

## Security issues

Do not report security vulnerabilities in public issues or on Discord. Use the
private reporting process in [SECURITY.md](SECURITY.md).
